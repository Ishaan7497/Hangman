# Hangman

A classic Hangman word-guessing game implementation in Python.

## About

This is a simple command-line implementation of the popular Hangman game where you guess letters to figure out a hidden word before running out of attempts.

## Features
- Interactive gameplay
- Word guessing mechanics
- Attempt tracking
- Python-based implementation

## Installation

Clone the repository:

```bash
git clone https://github.com/Ishaan7497/Hangman.git
cd Hangman
python hangman.py
```

## How to Play

1. Run the game
2. Guess letters one at a time
3. Try to figure out the word before your attempts run out
4. Win by guessing the complete word!
